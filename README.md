# FROOTY — PART 01

Clean Android foundation for the FROOTY assistant.

### Included
- Kotlin Android project
- Premium dark FROOTY UI
- AI orb foundation
- Chat area
- Text input + Send
- Hindi speech recognition
- Hindi Text-to-Speech
- Microphone runtime permission
- Basic local placeholder brain
- GitHub/code-phase friendly folder structure

### Important
This part intentionally does NOT use Gemini/Firebase AI yet. The placeholder brain will be replaced in Part 02.

### Code-phase checklist
1. Add the ZIP contents to your GitHub code project, preserving paths.
2. Build the project.
3. Run it on Android.
4. Confirm UI, text chat, voice recognition and spoken reply all work.
5. Keep these Part 01 files when adding Part 02.

- `app/src/main/java/com/frooty/ai/MainActivity.kt`
